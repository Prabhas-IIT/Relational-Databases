# Relational Database Projects

This repository contains my projects completed as part of the freeCodeCamp Relational Database Certification.

All projects were independently designed and implemented by me using PostgreSQL and SQL. The repository demonstrates my understanding of:

- Relational database design
- SQL queries
- Primary and foreign keys
- Constraints
- Normalization
- Joins and subqueries
- Database schema design

## Projects

- Celestial Bodies Database
- Salon Appointment Scheduler
- World Cup Database
- Periodic Table Database
- Number Guessing Game


## Tech Stack

- SQL
- Bash (where applicable)
- Git & GitHub
